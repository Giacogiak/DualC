# Settled decisions — the choices that hold

Part of the [decisions index](README.md). The decisions that shaped the architecture, the
scope and the process and are not re-litigated: each row names what holds, when it was
decided and the entry that holds the argument. Same columns and the same ID sequence as the
open table on the README; a row here never changes status (a settled decision that is
reversed gets a new row, on the README, with the new date). The present-tense *effect* of
these decisions lives in [`docs/design/`](../design/README.md) — this table is the pointer
to *why*.
